# Create 6 compatibility matrix — Minecraft 1.21.1

## Verified support target

For **Minecraft 1.21.1**, the published Create releases are currently in the **6.0.x**
line, with **Create 6.0.10** the latest release. The official file listing does not show
Create 6.1.x/6.2.x/etc. for Minecraft 1.21.1.

Therefore this project does NOT falsely advertise 6.1+ support.

| Create version | Minecraft | Status |
|---|---|---|
| 6.0.0–6.0.10 | 1.21.1 | Supported build line |
| 6.1.x+ | 1.21.1 | Not published/verified for this target |

When Create publishes a new 1.21.1 6.x line, add a new profile only after compiling
against the actual Create API and checking CEE + P&W compatibility.
