# Create profile usage

Current supported profile:

`gradle -Pcreate_profile=create_6_0 build`

This compiles against Create 6.0.10 and declares compatibility with the Create 6.0.x
line for Minecraft 1.21.1.

Do not install this build against an unverified future Create API. When a new Create 6.x
line is actually released for Minecraft 1.21.1, a new profile must be compiled and tested.
